## Grupos de rutas

Usa `helix.group()` para registrar varias rutas bajo un prefijo común y compartir middlewares entre ellas.

```typescript
import helix from '@helix-server/core'
import { Auth, RateLimit } from './middlewares'

helix.group({ prefix: '/api', middlewares: [{ class: Auth }] }, (api) => {
	// GET /api/users/:id — ejecuta Auth
	api.get({
		route: '/users/:id',
		async handler(ctx) {
			ctx.res.setJsonBody({ id: ctx.req.getParam('id') ?? null })
		},
	})

	// Los grupos se pueden anidar: prefijos y middlewares se acumulan
	api.group({ prefix: '/v1', middlewares: [{ class: RateLimit }] }, (v1) => {
		// GET /api/v1/ping — ejecuta Auth y RateLimit
		v1.get({
			route: '/ping',
			async handler(ctx) {
				ctx.res.setBody('pong')
			},
		})
	})
})
```

- Las barras entre el prefijo y la ruta se normalizan (`'api/'` + `'/users'` → `/api/users`, y `route: '/'` corresponde al propio prefijo).
- Los middlewares del grupo se aplican a todas sus rutas, junto con los middlewares propios de cada ruta.
- Si una ruta declara la misma clase de middleware que su grupo, prevalece la de la ruta (incluidos sus `args`).
