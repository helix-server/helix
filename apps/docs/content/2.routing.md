## Route groups

Use `helix.group()` to register several routes under a common path prefix and share middlewares between them.

```typescript
import helix from '@helix-server/core'
import { Auth, RateLimit } from './middlewares'

helix.group({ prefix: '/api', middlewares: [{ class: Auth }] }, (api) => {
	// GET /api/users/:id — runs Auth
	api.get({
		route: '/users/:id',
		async handler(ctx) {
			ctx.res.setJsonBody({ id: ctx.req.getParam('id') ?? null })
		},
	})

	// Groups can be nested: prefixes and middlewares are accumulated
	api.group({ prefix: '/v1', middlewares: [{ class: RateLimit }] }, (v1) => {
		// GET /api/v1/ping — runs Auth and RateLimit
		v1.get({
			route: '/ping',
			async handler(ctx) {
				ctx.res.setBody('pong')
			},
		})
	})
})
```

- Slashes between the prefix and the route are normalized (`'api/'` + `'/users'` → `/api/users`, and `route: '/'` maps to the prefix itself).
- Group middlewares are applied to every route in the group, together with the route's own middlewares.
- If a route declares the same middleware class as its group, the route's entry (and its `args`) takes precedence.
